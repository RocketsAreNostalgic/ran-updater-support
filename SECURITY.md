# Security

Before the first beta release, security reports about the development source
are welcome. Once beta releases are available, only the latest beta receives
security fixes.

Report suspected vulnerabilities through GitHub's private vulnerability
reporting form:

https://github.com/RocketsAreNostalgic/ran-updater-support/security/advisories/new

If that form is unavailable, use the [issue chooser](https://github.com/RocketsAreNostalgic/ran-updater-support/issues/new/choose)
and select `Security reporting help` only to request a confidential contact route.
This public form must contain no vulnerability details, exploit steps or reproduction traces.
Do not include vulnerability details, credentials, tokens, private repository
information, site data, temporary paths, archives, or log extracts in a public
issue.

Include the package version or commit and PHP version in a private report,
with steps to reproduce and the expected and actual behavior. This pure helper
does not require WordPress to report a defect.
