# Support

Before the first beta, reports about development source are welcome. Once beta
releases are available, the latest beta is the supported version. Use [a public issue](https://github.com/RocketsAreNostalgic/ran-updater-support/issues/new)
for ordinary support, reproducible non-sensitive defects, and feature requests.
There is no guaranteed response or resolution time.

Include the package version or commit, PHP version, a minimal reproducer, and
the expected and actual behavior. `ArchiveSafety` is a pure PHP helper, so a
WordPress installation is not needed for an archive-safety report.

Do not put vulnerability details, credentials, tokens, private repository
information, archives, temporary paths, site data, or log extracts in an issue
or pull request. Use [SECURITY.md](SECURITY.md) for confidential vulnerability
reporting. Send conduct reports through the private route in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
